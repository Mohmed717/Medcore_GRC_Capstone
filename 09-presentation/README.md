# 09 — Presentation

Target duration: 10–15 minutes.

Suggested story:

1. MedCore scenario
2. Scope and critical assets
3. Main threats
4. Risk methodology
5. Risk Matrix
6. Top risks
7. Controls
8. Framework / compliance gaps
9. Policies
10. Prioritized recommendations
11. Conclusion

Every member should understand and be able to explain their own decisions.
