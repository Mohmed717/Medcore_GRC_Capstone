# Framework Decision

## Selected framework

**NIST Cybersecurity Framework (CSF) 2.0**.

## Why this framework fits MedCore

NIST CSF 2.0 is appropriate for this design-phase assessment because it provides a common taxonomy for understanding, assessing, prioritizing, and communicating cybersecurity outcomes without prescribing a single implementation method. That flexibility fits MedCore's incomplete pre-implementation design, where the team must evaluate governance, identities, data protection, monitoring, response, recovery, and supplier risks before selecting detailed safeguards. The team will use the six CSF 2.0 Functions—Govern, Identify, Protect, Detect, Respond, and Recover—and will not mix ISO/IEC 27001 references into the control mapping.

## Version and references

The selected version is **NIST CSF 2.0**, published February 26, 2024, as NIST CSWP 29. The official publication and DOI are listed in `docs/reference-notes.md` and `10-evidence/references/source-register.md`.

## Application rule

Every gap in `05-compliance/framework-mapping.csv` and every risk in `03-risk-analysis/risk-register.csv` references one or more NIST CSF 2.0 categories or subcategories. Statuses are design-phase observations only: **Not Addressed**, **Partially Addressed**, or **Fully Addressed**. A planned control is not treated as operating evidence.
