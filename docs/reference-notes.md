# Reference notes

## NIST Cybersecurity Framework 2.0

- Official publication page: https://www.nist.gov/publications/nist-cybersecurity-framework-csf-20
- DOI / document: https://doi.org/10.6028/NIST.CSWP.29
- NIST describes CSF 2.0 as guidance for industry, government, and other organizations to manage cybersecurity risks, using a taxonomy of high-level outcomes that can be used regardless of organization size, sector, or maturity. It is not prescriptive about how outcomes must be achieved.
- Official framework landing page: https://www.nist.gov/cyberframework
- The project will use NIST CSF 2.0 consistently and will not mix ISO 27001 control references.
